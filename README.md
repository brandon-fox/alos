# ALOS — Local Autonomous Life Operating System

ALOS is a local-first, autonomous life operating system built with Python, Pydantic, pytest, and local spec-driven RAG architecture.

## Overview
- **Specs**: Feature specifications located in `specs/`.
- **Vault**: Local Markdown user profile, preferences, and correction ledger in `vault/`.
- **References**: Consolidated reference knowledge base in `references/`.
- **Developer Workflow**: Complete setup and governance guide in `GIT_WORKFLOW.md`.
